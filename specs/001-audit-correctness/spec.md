# Feature Specification: 修复研究评测与模型交付的 11 项问题

**Feature Branch**: `codex/superpnl-audit-fixes`
**Created**: 2026-10-04
**Status**: Approved for implementation
**Input**: 用户要求“创建 issue 并逐个修复”。对应 Shadowell/SuperPnL issues #1–#11。

## User Scenarios & Testing

### User Story 1 - 可核算的回测 (Priority: P1)
研究者需要使用可成交价格、真实资金约束和公平基准比较模型。
独立验收：入场前跳空不获利；两币等权一期 +100%/-50% 获利 25%；
净值 1→0.9→0.8 回撤为 -20%；动量以原始收益和 bps 比较。

### User Story 2 - 时间和数据版本可信 (Priority: P1)
研究者改变未来分区数据不能改变早期训练样本，缺失数据和缓存错配必须明确报错。
独立验收：修改验证/测试价格不影响前一分区标签；半数分钟缺失不能通过检查；
改变 horizons、lookback、特征窗口或原始文件不能复用旧缓存。

### User Story 3 - 模型包可验证且不丢失 (Priority: P1)
下游能加载 OHLCV 与有因子模型，且数据契约一致；失败不能破坏已有模型包。
独立验收：调换 horizon 顺序或统计量时拒绝打包；两类权重加载和推理通过；
缺少输入文件或构建失败时，旧包及 tarball 字节不变。

### Edge Cases
空分区、单期亏损、零仓位、价格跳空、缺失币种、无效价格、时间缺口、
旧版缓存/权重、同维度但不同顺序的特征、打包替换失败均明确处理。

## Requirements

### Functional Requirements
- FR-001 (#1): t 收盘决策，t+1 开盘成交，逐分钟收益以 t+1→t+2 开盘计算。
- FR-002 (#2): 组合使用现金与资产价值记账；成本基于实际成交名义金额，买入持有不自动再平衡。
- FR-003 (#3): 各分区样本的标签终点必须早于下一分区起点。
- FR-004 (#4): 严格保留 1m 时间尺度；缺失/无效数据明确拒绝，不压缩分钟或向后填充。
- FR-005 (#5): checkpoint 与缓存的数据来源、特征顺序、horizon、lookback、标准化统计须匹配。
- FR-006 (#6): 回撤计算包括初始净值 1。
- FR-007 (#7): 动量阈值比较采用原始收益单位。
- FR-008 (#8): 仅相同版本、配置与原始数据的缓存允许复用。
- FR-009 (#9): 模型包结构遵循实际 checkpoint，OHLCV 不要求因子编码器。
- FR-010 (#10): 输入验证、构建及替换失败时保留已有包与压缩包。
- FR-011 (#11): 安装声明覆盖绘图所需依赖。
- FR-012: 同步现有事实入口，历史指标标记为修复前结果，不伪造重算指标。

### Key Entities
数据集（分钟网格、分区、标签、标准化）；资金账本（资产/现金、成本、净值）；
版本化数据契约（来源与顺序）；模型包（权重、契约、哈希、配置）。

## Success Criteria

### Measurable Outcomes
- SC-001: 11 项 issue 各有独立修复提交，行为缺陷有失败到通过的回归测试。
- SC-002: 所有回归与小型 CPU 训练→评测→打包→加载流程通过。
- SC-003: 四类必需基准齐全，成本和期末按市值计价的口径明确。
- SC-004: 未改主工作区、不推送、不创建 PR、不部署、不运行真实数据重训。

## Assumptions
- 继续现货 long-only，信号取值 0..1，每币目标占组合的 signal/N，其余为现金。
- 策略逐分钟按目标权重再平衡，成本在成交中扣除；buy-and-hold 只在起点买入。
- 期末按市值计价、不强制平仓，不收取假设的期末卖出费用。
- 缺口明确拒绝，旧版未知契约产物要求重建/重训，不自动迁移。
- 本轮不新增特征；历史特征仍只读取决策时刻及以前数据。
